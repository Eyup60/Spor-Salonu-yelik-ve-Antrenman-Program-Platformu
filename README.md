# 🏋️ FitTrack Pro - Spor Salonu Yönetim Sistemi

FitTrack Pro, spor salonlarının günlük operasyonlarını dijitalleştirmek, üye performansını takip etmek ve antrenman yönetimini optimize etmek amacıyla geliştirilmiş masaüstü tabanlı bir Java uygulamasıdır.

## 🚀 Proje Hakkında
Bu proje, **CENG106 Object Oriented Programming** dersi kapsamında geliştirilmiştir. Projenin temel amacı, karmaşık verileri (vücut kitle endeksi, antrenman hacmi, ödeme periyotları) nesne yönelimli programlama prensipleriyle yapılandırarak, hatasız ve kullanıcı dostu bir deneyim sunmaktır.

## 🛠️ Kullanılan Teknolojiler ve Araçlar
* **Dil:** Java (JDK 17+)
* **Arayüz (GUI):** Java Swing & WindowBuilder
* **Veri Yönetimi:** JSON / CSV (Yerel Dosya Sistemi)
* **Versiyon Kontrolü:** Git & GitHub

## 🧩 Uygulanan OOP Teknikleri
Proje kapsamında akademik isterleri karşılamak adına aşağıdaki teknikler temel alınmıştır:
* **Kalıtım (Inheritance):** `Kullanici`, `Antrenman` ve `UyelikPaketi` abstract sınıfları üzerinden hiyerarşik yapı.
* **Çok Biçimlilik (Polymorphism):** Farklı antrenman türleri için dinamik hesaplama algoritmaları.
* **Soyutlama (Abstraction):** Interface kullanımı ile standartlaştırılmış veri işleme operasyonları.
* **Kapsülleme (Encapsulation):** Erişim belirleyiciler (private) ile hassas kullanıcı verilerinin güvenliği.
